# Python Practice

This repository stores my Python practice work from different learning courses.

## Repository structure

- Each course should have its own folder at the repository root.
- Each course folder should include its own `README.md` describing the course work.
- Course folders are intentionally not created yet; they will be added manually as I start each course.

Example future structure:

```text
.
├── README.md
├── LICENSE
├── .gitignore
├── <course-1>/
│   └── README.md
└── <course-2>/
    └── README.md
```
